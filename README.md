## Overview

Creative Mark helps investors establish, license and grow companies in Saudi Arabia. This repository contains the company's
public website and the dashboard its team uses to run it.

- **Public website** with a cinematic black-and-gold identity, a landmark slideshow, an interactive map of the 13 regions and
  six languages (Arabic, English, French, Hindi, Urdu, Simplified Chinese) with full right-to-left support.
- **Dashboard** where staff manage services, regions, FAQs, statistics, testimonials and countries in every language, with
  roles, permissions and two-factor authentication.
- **Content rules built in**: unverified figures never reach the public site, client names appear only with recorded consent,
  and editors' drafts go live only when a content manager publishes them.

## Features

### Public website
- Landmark slideshow (Riyadh, KAFD, AlUla, Historic Jeddah, Abha, NEOM): each photo moves from close-up to wide, the next
  one wipes in, and the copy describes the investment opportunities of that region. Pause control and a still version for
  visitors who prefer reduced motion.
- Home page sections: why invest, the Saudi journey, countries, sectors, track record, eleven business solutions, regions map,
  FAQ preview, consultation call to action and client reviews.
- About page built from the company presentation (positioning, market experience, local expertise with an
  international mindset, support after formation, six reasons to choose Creative Mark, verified track record).
- Business solutions: an overview page with the eleven services grouped Set up / Grow / Comply and the seven-step
  investor journey, plus a detail page per service (overview, what is included, related solutions, FAQs, consultation).
- Our edge page: what separates a registration from a business ready to operate, compared point by point, six reasons
  investors work with Creative Mark, markets served, the seven-step journey and verified figures.
- Regions: an overview with the interactive map and a photo card per region, plus a page for each of the 13 regions
  (where the opportunity lies, opportunities, leading sectors, location on the map, recommended solutions, more regions).
- Investor guide: eight chapters (why now, investor registration, company structures, licences, tax and zakat, hiring,
  incentives, residency and property) with key figures, practical steps and the sources behind every figure; chapter
  overview, floating reading progress, an interactive twelve-step checklist saved in the browser and a library of
  29 official and advisory sources.
- Newsroom: real market news summarised by the team, each story with what it means for investors, key figures and a
  link to the original report; full-screen broadcast opening that plays the top stories, live Riyadh time, scrolling "Latest" ticker, topic filter and a page
  per story with related stories.
- Case studies: each told in four chapters (starting point, our steps, what was delivered, where it leads) with an
  at-a-glance bar, a sticky chapter index, a timeline that fills as you scroll, the region on the map and the services
  used; sector filter on the overview. Examples built from the standard engagement are labelled "Illustrative example".
- Start your company: the formation journey, investor registration, legal structures and licences (with sources),
  everything the team handles, questions and a booking link that pre-selects company formation.
- FAQ with topic filters and search; contact page with both offices, maps links and every published channel;
  privacy policy and terms of use describing what the site actually does; designed 404 and error pages in six
  languages; `sitemap.xml` with hreflang alternates and a `robots.txt` that blocks indexing outside production.
- Consultation booking in four steps (needs, contact details, date and time, review): working days Sunday to Thursday,
  fixed slots in Riyadh time, a slot can be held by only one booking, reference number and confirmation page.
- Interactive map of the 13 regions: keyboard operable, sector filter, list alternative, screen-reader announcements.
- Motion system (GSAP, ScrollTrigger, Lenis): reveal, parallax, counters and line-draw presets chosen per section.
- Localized URLs (`/ar`, `/en`, `/fr`, `/hi`, `/ur`, `/zh`), Arabic by default, per-script typography
  (Amiri, IBM Plex Sans Arabic, Noto Nastaliq Urdu, Noto Sans Devanagari, Cormorant Garamond, Manrope).
- Responsive images (WebP up to 2560 px), lazy-loaded map, initial JavaScript under 180 KB gzip.

### Dashboard (`/admin`)
- Eight staff roles and 25 permissions; access denied by default and enforced on the server.
- Two-factor authentication required for Super Admin, Content Manager and Sales Manager.
- Content modules with one tab per language and a review status per language.
- News module: headline, summary, article, investor takeaway and key figures per language; topic, photo, report date,
  source name and https link; lead-story flag; draft and publish.
- Dashboard in Arabic and English (switch in the top bar, remembered per staff member; a test fails if any Arabic
  dashboard string is untranslated), bright ivory-and-gold theme with optional dark mode, Arabic typography.
- Page editor (Pages › Home page, About us; Business solutions › the solutions page and each of the eleven
  solutions, listed in the menu): move sections up and down or drag them, hide, add, duplicate or delete them;
  edit every text in six languages, images (with upload: re-encoded to WebP), buttons, cards, hero slides,
  background, spacing and animation. Save a draft, preview it in any language, publish (Content Managers),
  translate missing languages or discard unpublished changes. Two people saving at once never overwrite each other.
  Google title and description per language with a live search preview; version history with restore.
- Floating WhatsApp button (number in Settings › Contact details, with phone, email and social links), greeting
  pre-filled in the visitor's language; hidden on the booking form.
- Home page shows the latest three news stories and two case studies with links to all of them.
- Figures and client reviews can be added, edited, reordered and deleted from the home page editor ("Figures",
  "Client reviews") as well as from Content › Statistics and Content › Testimonials.
- Investor journey steps (Services and Start your company pages) edited in six languages; icon picker with
  previews (87 icons, generated by `scripts/build-cms-icons.mjs` for both the site and the dashboard); image
  pickers with thumbnails and upload in every module.
- Dashboard home: greeting with today's figures, quick actions per permission, booking statistics with trends,
  bookings per day, by status, by service and by client country, the next consultations and content health.
  Sales agents see only their own bookings; content staff see content figures only.
- Consultations: every booking with status, assignment, internal notes, email delivery status and reply history;
  "Reply by email" sends a branded email to the client from the dashboard; sales agents and consultants see only
  bookings assigned to them. Booking email recipients are managed in the dashboard (add, disable, send a test).
  New bookings raise a bell notification for managers.
- Case studies module: story per language (client description, legal form, starting point, steps, deliverables,
  outcome); sector, client country, region, services, photo; illustrative flag and client consent date (RULE-02).
- Draft and publish workflow: editors save drafts, content managers publish.
- "Translate missing languages" action and automatic filling of empty languages after saving.

### Notifications
- Each new booking emails every active recipient separately (replying reaches the client), sends the client a
  confirmation in their language, and notifies managers in the dashboard. Emails are designed in black and gold,
  right-to-left for Arabic and Urdu. A failed email never loses the booking: the error is recorded and can be resent.

### Translation
- Professional translations of every site string in French, Hindi, Urdu and Chinese (translation memory).
- Self-hosted machine translation (LibreTranslate) for new content, with a free fallback service, protected brand and place
  names, and a phrasebook for menu terms. Text written or reviewed by a person is never overwritten.

## Getting started

### Requirements
- PHP 8.3+ (developed on 8.5) and Composer
- Node.js 20+ and npm
- MySQL 8 or MariaDB 10.4+
- Docker (optional, for machine translation)

### Installation

```bash
git clone https://github.com/m77mdabdo/creative_mark.git
cd creative_mark
composer install
npm install
cp .env.example .env
php artisan key:generate
```

Create the database and its two users (run once with an account that can grant privileges, after replacing the two
placeholder passwords), then put the same credentials in `.env`:

```bash
mysql -u root -p < database/setup/001_create_database_and_users.sql
```

Build the schema and content, then start the site:

```bash
php artisan migrate --database=mariadb_migrate
php artisan db:seed
npm run build
php artisan serve
```

The site runs at `http://127.0.0.1:8000`; the dashboard is at `/admin`. Create the first administrator interactively:

```bash
php artisan cm:create-admin
```

### Translation service (optional)

```bash
docker compose -f infra/translation/docker-compose.yml up -d
php artisan cm:translate --publish
```

## Testing

```bash
php artisan test
npx tsc --noEmit
npm run build
```

Responsive check across 12 device widths (no horizontal scrolling, one heading, no script errors):

```bash
node tests/e2e/responsive.mjs /about ar,en,fr,hi,ur,zh
```

The suite covers locale routing, content rules, publishing, page-block validation (including injection attempts), every
role × permission combination, dashboard access, two-factor enforcement and the translation pipeline.

## Security

- Dedicated database with a runtime user limited to data access and a separate migration user; no root credentials.
- Deny-by-default authorization checked in policies for every dashboard action.
- Two-factor secrets and recovery codes encrypted at rest; strong password rules.
- Page content is structured data validated on the server; text is never rendered as HTML and links are allow-listed.
- Booking form: strict validation against fixed lists, no HTML, honeypot and minimum fill time against bots, rate
  limits per device and per email, slot locking against double booking, IP stored only as a keyed hash, explicit
  consent recorded. Mail credentials live only in `.env`.
